## 0. 实装口径

| 项 | 现在的做法 |
|---|---|
| 作用范围 | 月/周/年网格底色、侧栏图例点、日期数字（周末红）、今天环、应用底色、面板边框 |
| 「已完成」色阶 | 各主题的 `done` 字段 = 该主题的绿色 5 档 |
| 用户自定义色 | 忙度色阶若被用户改过（≠旧默认琥珀/钢蓝），保留用户色，主题不覆盖 |
| 鲜明模式 | 保留；与柔和模式共用同一组 5 档，只有填充强度不同 |
| 未覆盖 | 按钮/链接等「动作色」仍为蓝（`#2563EB`），未跟随主题 |

## 1. 配色逻辑

月网格里其实有三套独立的 5 档色阶，后端 level 0–4 对应 L1–L5：

| 色阶 | 含义 | 冷暖 | 用在哪 |
|---|---|---|---|
| 预测 / 忙度 | 未来日期的待办压力 | 暖色 | 月网格整格热度 |
| 已完成 | 过去日期的完成量 | 冷色 | 月网格整格热度 |
| 充实度 | `coloring_level` | 绿色 | 月网格整格热度 |

规则：

1. **同一个月最多同时出现两套色阶**：过去是冷色，未来是暖色，今天可能双层。两套色阶必须属于同一个色系，不能一个莫兰迪、一个高饱和。
2. **L1–L5 首先按明度排序**，其次才是色相变化。用户要能一眼排出「哪几天更忙」。
3. **柔和模式 = 原色 65% + 白 35%**；鲜明模式 = 原色 100%。两套都用同一组 L1–L5。
4. **文字颜色自动选**：浅档用近黑 `#111827`，深档用白。柔和模式因为混了白，L1–L5 基本都能用深色字。
5. **图层色（左侧条/圆点/日程类型）取 L4 或独立 accent**，不要取 L1，否则在白底上消失。
6. **周末红只用在日期数字**；今天用 ring；不和整格热度抢。

## 2. 四个方向

### Morandi / 莫兰迪

灰调、低饱和，像旧墙纸、亚麻布和陶土。优点是长时间看不累，缺点是阴天/低亮度屏幕上可能显得“脏”。

## 3. 我的判断

- **日常最稳**：Morandi。降噪最彻底，和现在的灰白界面最容易接上。
- **最“轻”**：Scandinavian。适合大留白和更现代的排版；但 L1–L2 需要更明确的边框/色条。
- **最有性格**：Mid-century Modern。如果希望应用有“温度”和辨识度，这个方向更合适。
- **最戏剧化**：Art Deco。不建议整月铺满，建议只取它的蓝/绿/金做强调色，或留给年度视图。

## 4. P0「月网格降噪」最终口径（v4）

v3 的 62% 固定白混把 5 档压成了一片相近的浅色，看着干净但**读不出谁更忙**，
等于废掉了热力图功能。v4 把「浅」和「有梯度」拆成两件事分别解决：

| 通道 | 取值 | 作用 |
|---|---|---|
| 色阶本身 | 按 HSL 明度重排为 `[0.95, 0.87, 0.77, 0.66, 0.53]`（暖色档 `[0.95, 0.87, 0.78, 0.67, 0.54]`） | 手写色阶常见「前两档撞色、后两档断崖」，重排后每档等距可辨 |
| 整格底色 | 重排后的色阶与白 **45%** 混合 | 整体仍是浅纸色，不压文字；梯度靠上一步保住 |
| 左侧细条 | **4px 满色** | 满强度的刻度，扫一眼就能排序 |
| 文字 | `softTextColor()` 按底色亮度自适应 | 45% 白混后全档都是深色字，不再出现白字块 |

`rebalanceRamp()` 只重排明度，色相与饱和度取原色阶末档，所以每套主题的色系没变，
变的只是「5 档之间是否等距」。5 套主题（含 classic）统一走这条规则。

年视图格子只有十几像素，柔和模式用 `softTint(color, { dense: true })`（30% 白混），
比月网格更实一点，否则小格会糊成一片白。

对照图：`release/taste-preview/theme-shell-before-after.png`

可调点：`frontend/src/data.ts` 的 `softTint()` 里 `const white = … 0.45`；
想让整月更淡就调大，想让强弱更冲就调小。改这里会同时影响所有主题。

## 5. 外壳配色（v2.4）

主题早期只改月网格，外壳仍是纯白，切换主题时会出现「暖色日历 + 白面板」的割裂。
现在每套主题定义三层外壳色，同色系不同明度：

| 变量 | 用在哪 | 取色原则 |
|---|---|---|
| `--cal-panel` | 顶栏、左侧栏、右侧栏、待办左栏、倒数日左栏 | 带明确色调但明度较高，一眼看出「这是莫兰迪/中世纪」 |
| `--cal-surface` | 日历区、待办任务区、倒数日内容区 | 近纸白，承托格子和文字 |
| `--cal-shell` | 窗口最底层（露在栏与内容之间） | 最深一档，给整体一个边框感 |

内容卡片（年视图月份卡、倒数日卡片）保持纯白，形成
`shell → panel → surface → card` 四级层次，卡片始终是「浮起来」的那一层。

## 6. 主题化调色板

「新建图层 → 涂色图层 → 五档颜色」原来的 8 套调色板是 Material 色卡（大红大绿），
和任何艺术主题都不搭。现在每套主题用 `buildPalettes()` 按同一组参数生成 8 套：

- 8 个基色相固定（绿 148 / 蓝 213 / 橙 26 / 紫 279 / 红 0 / 青 186 / 靛 238 / 灰 215）
- 每套主题只描述「饱和度上限 + 5 档明度 + 色相偏移」，于是 8 套天然成套
- 灰阶单独压到低饱和，避免发脏
- 已存在的图层保留当时写入的色值，不会被主题静默改写

## 7. 后续可做

1. 「动作色」（新建按钮、链接、toast 的撤销）仍固定蓝 `#2563EB`，未接主题 accent。
2. 侧栏 `待办·已完成` 图例固定取 L4；若想更直白可画成 5 档小色条。
3. 弹窗（新建/设置）仍用纯白底，与面板色形成 `white` 浮层；如果希望完全统一可改 `--cal-panel`。
4. 若嫌某套主题的外壳太重，直接调 `calendar-theme.tsx` 里该主题的 `panel` 值即可，其余不动。
